# TRACE — контекст для Claude Code

Читайте [подробную передачу проекта](docs/CLAUDE_CODE_HANDOFF.md) перед крупными изменениями, публикацией или работой с DNS.

## Проект

- Русскоязычный статический сайт TRACE: добровольная локальная диагностика игровых клиентов Minecraft, GTA V/RP и CS2. Сайт показывает команды и методику; браузер не сканирует ПК и не отправляет отчёты.
- Публичный репозиторий: `https://github.com/TraceOwner/tracecheck`. Рабочий домен: `https://trust-trace.lat/`. Продакшен собирает GitHub Actions из ветки `main` и публикует `dist/` через GitHub Pages.
- Здесь может быть локальная ветка `public-pages`, отслеживающая `github/main`. Старый локальный `main` и remote `origin` относятся к прежнему Sites-хостингу. **Не сливайте старую ветку `main` в публичную историю и не публикуйте её коммиты:** старую историю намеренно исключили из публичного репозитория.

## Команды

- `npm run build` — собрать HTML и большую часть ресурсов в `dist/`.
- `npm run hero3d` — пересобрать 3D-сцену главной (`-- --poster`, `-- --og`, `-- --glyphs` — постер, OG-картинка, контуры букв); нужен `npm install`.
- `npm run check` — проверить синтаксис ключевых JS/MJS файлов.
- `npm run dev` — локальный предпросмотр на `http://127.0.0.1:4173`.
- `node scripts/verify-commands.mjs` — после сборки разбирает все команды и файлы, проверяет пределы cmd.exe, правило арта и что строка для CMD даёт то же дерево разбора, что вкладка PowerShell, и прогоняет поиск на синтетических папках. На Windows использует Windows PowerShell и настоящий cmd.exe, в других системах — `pwsh` (или путь из `POWERSHELL`).
- `node scripts/perf.mjs` — при запущенном `npm run dev` открывает сайт в настоящем headless Chrome (с GPU машины) и печатает загрузку и провалы кадров при открытии меню, списка игр и инструкции. Запускайте после правок анимации; сравнивайте с прежним результатом на той же машине.
- `git status -sb` и `git diff --check` — проверка перед коммитом. В этом рабочем каталоге публикация: `git push github HEAD:main` **только с актуальной ветки `public-pages`**, после проверки diff и `git fetch github`.

## Исходники и важная ловушка сборки

- `src/site.mjs` строит семь страниц (вместе с 404); `src/home-page.mjs`, `src/check-page.mjs`, `src/tools-page.mjs` содержат разметку, `src/icons.mjs` — SVG-иконки интерфейса. `src/commands.js` собирает все команды проверки (см. ниже), `src/check.js` управляет игрой, способом, задачей и копированием.
- Движение: `src/spring.js` — пружинный движок (`TraceMotion`: Spring, Motion, Lens, Morph, animate, morphHeight), `src/site.js` — общий UI (`TraceUI`: шапка, диалоги, остров-уведомления, появления, FAQ, линзы), `src/motion.js` — оркестрация WebGL-дыма; шейдер и цикл кадров в `src/smoke-core.js`, Worker-обёртка `src/smoke-worker.js`. Большое слово TRACE на главной — 3D-сцена three.js: `src/hero3d/scene.js` (буквы из `src/hero3d/glyphs.json`, свечение; лупу владелец велел убрать 2026-10-08), `src/hero3d/worker.js` (OffscreenCanvas; рисует каждый N-й кадр экрана — около 60 в секунду при наведении, 30 в покое и при прокрутке; лестница качества по бюджету пикселей; страница сообщает ему, когда сама теряет кадры), `src/hero3d.js` на странице (запуск после загрузки, ворота «видно / вкладка / пауза», при наведении буква под указателем выходит вперёд — `scene.js`; свет за указателем владелец отверг; ESP-прицел владелец велел убрать 2026-10-08). Сборка — `npm run hero3d` (`scripts/hero3d-build.mjs`; нужны dev-зависимости, результат закоммичен в `dist/`). Постер `hero-poster.webp` (и `-960`, `-2870` для srcset) — первый кадр сцены при раскладке 1440×900; он стоит в HTML, место задаёт CSS в единицах кегля слова (`.hero3d-poster` в `trace.css`). **Если меняете кегль, отступы или межбуквенный интервал слова, пересоберите постер** (`npm run hero3d -- --poster` при запущенном `npm run dev`) и проверьте, что сцена встаёт на постер без сдвига. Телефоны (до 720 px), reduced motion, принудительные цвета, экономия трафика, слабые устройства и браузеры без OffscreenCanvas в Worker получают только постер; при смене этих условий сцена уходит, постер возвращается. Сцена проявляется под постером, потом уходит постер; если страница уже прокручена, подмена ждёт возврата наверх. MSAA в сцене выключен намеренно (давал рывки прокрутки), сглаживание — FXAA. **Не возвращайте перегруженную первую версию оверлея** (скелеты, трейсеры, радар, меню, лента выстрелов, демо «аимбота»). Обычное DOM-слово `.cinema-word > span` остаётся под постером: оно задаёт размер блока и показывается без JavaScript и в режиме принудительных цветов. За 3D-словом на главной идёт дым (владелец 2026-10-03: фон первого экрана должен двигаться); у него буфер не шире 720 px, а во время прокрутки он рисует каждый третий кадр. Заголовки разделов появляются «из тумана» (подъём с размытием) — это выбор владельца, маску вместо него он отверг. `src/field.js` — поле нитей в финальном блоке главной. Печатный слой (`print.js`: растр, штампы, метки обреза, линия отреза) владелец велел убрать 2026-10-03; он остался только в истории git. Все стили — один файл `src/trace.css`; пружинные easing `--spring-*` генерирует `npm run springs` (`scripts/springs.mjs`) — меняйте параметры там и вставляйте результат в токены.
- Старые CSS/JS предыдущих версий и неиспользуемые TTF-шрифты удалены из `src/` и `dist/` (остались в истории git); `src/hero-trace.png` — исходник; `hero-trace.jpg` из него получается командой `node scripts/bake-hero.mjs` (размытие и обесцвечивание запечены в картинку, поэтому CSS не применяет `filter` к слою героя).
- Производительность (проверено на реальном GPU, не на предположениях): дым рисуется в Worker; параллакс героя — CSS scroll-driven animations (`animation-timeline: scroll()`), JS пишет `--scene` только там, где их нет; поверхности с размытием и большими тенями «прогреваются» через `TraceUI.warm(build, {hold})` — первая отрисовка `backdrop-filter`, больших теней и SVG-фильтра компилирует GPU-программы и даёт подвисание в первых кадрах анимации. Новая поверхность с такими эффектами, которая впервые появляется во время анимации, должна регистрировать копию для прогрева. Не оставляйте CSS `transition: transform` на элементах, которые JS двигает каждый кадр: переход стартует заново на каждом кадре. `backdrop-filter` на панели, которая движется или меняет размер, — самый дорогой эффект: меню и диалоги открываются без него и получают класс `is-settled` (site.js) по завершении, а вместо фильтра на каждой строке размывается весь контейнер.
- Смена высоты блока (способ, задача, FAQ, список названий) идёт через `TraceMotion.morphHeight(element, mutate, {inside})` (2026-10-26): до `mutate()` замеряются экранные позиции следующих блоков, после — каждый из них возвращается на место одной пружиной через свойство `translate`. Чтобы при уменьшении страницы у нижнего края не было скачка прокрутки, внизу ставится временный `.flip-spacer`, `overflow-anchor` выключается, а прокрутка доезжает вместе с пружиной; колесо, касание или клавиши прокрутки сразу завершают движение. Не меняйте высоту таких блоков в обход `morphHeight` и не ставьте CSS-переход на `translate` у следующих блоков. Раскрытие `.faq-list details` и `.names-panel` — общий помощник в `site.js` (при закрытии сворачивается копия содержимого). Переходы между страницами — View Transitions: подсветка текущего пункта меню (`.nav-pill`, `view-transition-name: nav-current`) переезжает к новому пункту, шапка не двигается (навигация по центру сетки из трёх колонок, поэтому кнопка «Открыть проверку», которой нет на странице проверки, её не сдвигает), заголовок страницы перетекает, только если он на экране; класс `.vt-arrival` отключает обычные анимации появления первого экрана, чтобы он не появлялся дважды.
- Команды (владелец 2026-10-23): на странице выбирается задача — «Всё сразу», процессы, Prefetch, реестр, корзина, Defender, автозапуск, службы и журналы, hosts, папки игры, классы в JAR (только Minecraft), все диски; регулятор глубины убран. Все команды собирает `src/commands.js` из одних блоков PowerShell: вкладка PowerShell показывает их скриптом в `& { … }`, вкладка CMD склеивает те же строки в одну `powershell -NoProfile -Command "…"` (cmd.exe выполняет каждую вставленную строку отдельно и держит не больше 8191 символа). Поэтому в блоках нельзя: комментарии, двойные кавычки, `%`, многострочные `( … )`. «Всё сразу» для Minecraft в PowerShell — TRACE-PRO с `-Preset minecraft`; в CMD «Всё сразу» не помещается в строку и запускает скачанный файл (`trace-pro-minecraft.ps1`, `trace-gta.ps1`, `trace-cs2.ps1`; два последних пишет сборка из тех же блоков). Списки названий Minecraft (`$cheatKeywords`, `$weakKeywords`, `$jarSignatures`, `$gameRoots`) сборка берёт из `src/trace-pro-minecraft.ps1`; списки GTA V RP и CS2 — в `games` в `commands.js`. Под командой страница показывает тот же список, которым ищет команда. Правило совпадения одинаковое на странице и в TRACE-PRO (`scripts/verify-commands.mjs` сверяет их на примерах): отличительные названия ищутся как часть имени, общие слова (`weak`) — только отдельным словом; папка пользователя `C:\Users\<имя>` в сравнение не входит; если в строке есть и отличительное название, и общее слово, показывается отличительное. Сигнатуры классов в JAR — это папки пакетов (`(^|/)имя/`). В CMD «Всё сразу» запускает самый новый `trace-…*.ps1` из папки «Загрузки» (браузер добавляет к повторной загрузке « (1)»). Терминал на странице показывает строку CMD с переносами по операторам (`code.is-oneline`, перенос делает CSS), в буфер попадает одна строка.
- Арт: первое копирование каждой команды (способ, игра, задача) — с заставкой TRACE, все следующие — без неё (владелец 2026-10-23); повторное копирование сначала перерисовывает терминал, чтобы на странице было ровно то, что в буфере. Для TRACE-PRO и файлов это `-SkipIntro`.
- Minecraft-сценарий по-прежнему принимает `-Preset quick|system|minecraft|full|menu`; эти режимы доступны в его меню и в скачанном файле.
- GTA V RP: RAGE:MP закрыт 31.08.2026, ролевые серверы переходят на FiveM; список GTA содержит меню FiveM из списков античитов, меню GTA Online и названия продавцов GTA5RP/Majestic. Общие слова помечены как `weak` (находка с пометкой «возможно ложное совпадение»).
- `src/trace-pro-minecraft.ps1` генерирует команду Minecraft и публикуется в `dist/scripts/`; не редактируйте генерируемый `dist/minecraft-command.js` как источник.
- `dist/` закоммичен и является содержимым сайта. **Не удаляйте его перед сборкой:** сборщик не восстанавливает `dist/fonts/` (их обновляет `node src/font-vendor.mjs`), `dist/scripts/trace-check.ps1` и `dist/scripts/trace-check.cmd` (их больше нет на странице проверки, но они описаны в юридических документах и в блоке для браузеров без JavaScript). Юридические документы теперь собираются из `src/legal-docs.mjs` прямо в `legal.html` (все пять в HTML, нужный показывает встроенный скрипт до первой отрисовки, чтобы подвал не прыгал).
- После изменения исходников всегда собирайте сайт и проверяйте `git diff` как исходников, так и `dist/`.

## Критерии изменений

- Типографика: **Literata** (вариативная, вес 400–600, урезана до используемых символов, один файл ~42 КБ) — все H1/H2 и крупные надписи; **Golos Text** — текст и интерфейс; **IBM Plex Mono** — метки и данные; **Unbounded** — только логотип (урезан до букв «TRACE.» и веса 700, ~1 КБ; предзагрузка шрифтов в `site.mjs` берёт имена файлов из `trace-fonts.css`). Если в заголовке нужен новый символ, добавьте его в `literataText` в `src/font-vendor.mjs` и перегенерируйте шрифты. Запасные шрифты с `size-adjust` описаны в начале `src/trace.css`. В первом экране главной только 3D-слово по центру, без кнопок и текста (владелец 2026-10-08); заголовок H1 скрыт визуально. Финальный блок главной — только заголовок над полем нитей, без кнопки и моноширинной подсказки (владелец 2026-10-23). Страница проверки разгружена (владелец 2026-10-23): без шагов «Шаг 1/2/3», бейджа платформы, колонки «Кто запускает», длинных пояснений и нижнего блока; игра и способ — в левой колонке, справа задача, команда и сворачиваемый список названий. Анимацию оси веса на наведении пробовали и убрали: на каждом кадре браузер заново раскладывает текст (919 мс раскладки на 6 наведений против 26 мс).
- Палитра чёрно-белая (владелец, 2026-10-03): графит и белый, медь больше не акцент. Материал поверхностей — матовый графит: непрозрачные панели, тонкий светлый кант, белая подсветка края под указателем (`.trace-surface::after`). **Не возвращайте «ликвид гласс»** (полупрозрачность, `backdrop-filter`, глянцевые линзы). Декоративная нумерация «01 / 02 / 03» убрана: номера только у настоящих последовательностей.
- Сохраняйте характер интерфейса: строгая технологичная типографика, тёмные объёмные поверхности, выразительная и плавная анимация без шаблонного «ИИ-дизайна». Особое внимание — раскрытию списка игры и уведомлению о копировании: они должны быть цельными, объёмными и закреплёнными относительно окна при прокрутке.
- Проверяйте клавиатуру, фокус, Escape, `prefers-reduced-motion`, контраст и производительность. Предпочтение владельца — сначала качественный desktop-опыт.
- Тексты: простой конкретный русский, как пишет человек, который сам проверяет игроков. Название — `TRACE` в логотипе и метках, `Trace` в обычном тексте. Не возвращайте лозунги-параллелизмы («Меньше X. Больше Y.», «Не X. А Y.»), вопросы в заголовках, абстрактные слова («сигналы», «ориентиры», «адресный», «зацепка», «срез»), тройки прилагательных, восклицания и лишние тире. Каждая фраза говорит что-то проверяемое о работе сайта. Юридические документы (`src/legal-docs.mjs`) владелец попросил писать очень подробно; реквизиты — только заглушки `[ФАКТ: …]`.
- Не представляйте совпадение имени, хеша или файла как доказательство читерства; сверяйте актуальные источники и правила серверов. Не добавляйте скрытое сканирование, сетевую отправку или запуск команд без явного действия пользователя.
- Юридические документы — черновики с непроверенными реквизитами (ФИО и телефон указаны владельцем, остальное — заглушки). Не называйте их утверждёнными и не подставляйте вымышленные данные. Описания команд и скриптов в них должны совпадать с кодом `src/check.js` и `dist/scripts/`.
- Не добавляйте в Git ключи, токены, учётные данные, локальные настройки Claude или личные файлы. Не меняйте DNS/хостинг без проверки текущего состояния; старый `.openai/hosting.json` не управляет продакшеном.
