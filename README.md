# TRACE

TRACE — независимый сайт для добровольной локальной проверки игровых клиентов. Он помогает собрать сведения и оценить их в контексте правил конкретного проекта. Браузер не читает устройство, не загружает отчёты и не выносит вердикт о читах.

Публичный сайт: [trust-trace.lat](https://trust-trace.lat/). Исходники и деплой через GitHub Pages: [TraceOwner/tracecheck](https://github.com/TraceOwner/tracecheck). Для продолжения разработки в Claude Code начните с [`CLAUDE.md`](CLAUDE.md) и [передачи проекта](docs/CLAUDE_CODE_HANDOFF.md).

## Структура

- `index.html` — обзор и прямые переходы к трём способам проверки.
- `check.html` — адресные команды PowerShell/CMD для Minecraft, GTA V/RP и CS2, ориентиры по именам, источники, ручная проверка и локальный чек-лист.
- `methodology.html` — порядок оценки процессов, файлов и контрольных сумм; короткие ответы.
- `projects.html` — ссылки на страницы Minecraft, FunTime, SpookyTime, ReallyWorld, HolyWorld, GTA5RP, Majestic и Counter-Strike 2. Упоминание не подтверждает партнёрство.
- `tools.html` — инструкции и проверенные источники JournalTrace, Everything, System Informer, WinPrefetchView, Shellbag Analyzer, RegScanner, RecentFilesView, FunModAnalyzer и Ocean.
- `legal.html?doc=...` — отдельные адреса для оферты, политики данных, согласия, правил и cookie.

Исходники интерфейса лежат в `src/`, готовые файлы — в `dist/`. PowerShell и CMD скрипты остаются в `dist/scripts/`. Общие страницы собираются из `src/site.mjs`, главная — из `src/home-page.mjs`, рабочие страницы — из `src/check-page.mjs` и `src/tools-page.mjs`. Все стили — в `src/trace.css`. Пружинный движок анимаций — `src/spring.js`, поведение интерфейса — `src/site.js` и `src/check.js`, дым — `src/motion.js` (страница), `src/smoke-core.js` и `src/smoke-worker.js` (шейдер и Worker). 3D-слово на главной — `src/hero3d.js` (страница), `src/hero3d/scene.js` (сцена three.js), `src/hero3d/worker.js` (Worker), сборка — `scripts/hero3d-build.mjs`.

```text
npm run build
npm run check
npm run dev
```

Предпросмотр доступен по адресу `http://127.0.0.1:4173`. После изменения исходников следует выполнить `npm run build`; для этого зависимости npm не нужны.

`npm run hero3d` пересобирает 3D-сцену (`dist/hero3d-scene.js` с three.js, `dist/hero3d-worker.js`). С ключом `-- --poster` при запущенном `npm run dev` и установленном Chrome он заново снимает постер (первый кадр сцены при раскладке 1440×900), с `-- --og` — картинку для ссылок `og-image.jpg`, с `-- --glyphs` — контуры букв из Golos Text. Для этого нужны dev-зависимости: `npm install` (three, esbuild, opentype.js). Готовые файлы лежат в `dist/`.

## Логотип и визуальная система

Знак TRACE — асимметричный радиальный сигнал: лучи сходятся в точке, смещённой вправо-вниз. Он отсылает к поиску следа и читается в шапке и favicon. Источник вектора — `src/brand.mjs`, статическая иконка — `dist/brand.svg`.

Основные шрифты Unbounded, Golos Text и IBM Plex Mono размещены локально в `dist/fonts/`; заголовки набраны вариативной Literata (вес 400–600, урезана до используемых символов, один файл около 42 КБ). Используются WOFF2-подмножества для латиницы и кириллицы; лицензии OFL лежат рядом. `src/font-vendor.mjs` обновляет эти файлы из официального каталога Google Fonts при необходимости.

## Доступность и анимация

Во вступлениях страниц и на странице документов WebGL рисует графитовый дым: несколько слоёв шумовой функции создают изменяющиеся завихрения, а редкие светлые импульсы подсвечивают отдельные участки облака. Фон реагирует на указатель и прокрутку. Шейдер живёт в `src/smoke-core.js` и рисуется в Web Worker на OffscreenCanvas (`src/smoke-worker.js`): создание контекста, компиляция шейдера и кадры не занимают основной поток страницы. Если Worker или OffscreenCanvas недоступны, тот же код работает в основном потоке. Кадры идут ровным ритмом по частоте монитора (не выше примерно 72 в секунду); при нехватке мощности сначала снижается разрешение, и только потом частота; ширина буфера ограничена 1080 px. Холст создаётся, когда блок приближается к окну; вне экрана, за модальным окном и в скрытой вкладке отрисовка стоит. Если WebGL недоступен или контекст потерян, остаётся CSS-дымка. Заголовки появляются цельными строками с коротким рассеиванием размытия; буквы не разделяются на элементы. Стили находятся в `src/trace.css`.

Большое слово TRACE на главной — 3D-сцена на three.js: выдавленные буквы из тёмного хрома, студийное окружение и лёгкое свечение. Сцена рисуется в Web Worker на OffscreenCanvas, загружается после страницы и только на экранах шире 720 px; где OffscreenCanvas в Worker нет, остаётся постер. Она рисует около 60 кадров в секунду, пока указатель над героем, и 30 в покое и во время прокрутки, при любой частоте экрана. Если не успевает сама сцена или начинает терять кадры страница, сцена снижает число пикселей, затем выключает свечение, а если и это не помогает, уступает место постеру. Вне экрана, в скрытой вкладке, за открытым меню и при паузе движения отрисовка стоит.

Постер (`hero-poster.webp`, а также `hero-poster-960.webp` и `hero-poster-2870.webp` для узких окон и экранов с двойной плотностью) — первый кадр той же сцены. Он стоит в HTML с самого начала, а место ему задаёт CSS в единицах кегля слова, поэтому живая сцена проявляется поверх него без сдвига. Телефоны, режим экономии трафика, слабые устройства, принудительные цвета и `prefers-reduced-motion` получают только постер. Сцена проявляется под постером, и только потом постер уходит, поэтому слово не тускнеет при подмене. Без JavaScript, в режиме принудительных цветов и если постер не загрузился, остаётся обычное текстовое слово.

Слово стоит в центре первого экрана, больше там ничего нет; заголовок страницы остался только для экранных дикторов. Без наведения по буквам медленно идут отражения. При наведении буква под указателем выходит вперёд и чуть поворачивается к нему, соседние следуют слабее, а по металлу за указателем скользит мягкий свет. При прокрутке буквы расходятся в глубину.


Выбор игры — доступный список с клавиатурным управлением: стрелки передвигают активный пункт, Enter подтверждает его, Escape закрывает список, а набор букв ищет название. Визуальные строки появляются по очереди и расходятся в обратном порядке при закрытии. Базовое значение остаётся в нативном `<select>`, чтобы ссылки с `?game=...`, чек-лист и инструменты продолжали читать тот же выбор.

Поверхности — матовый графит: непрозрачные панели, тонкий светлый кант и белая подсветка края под указателем. У ссылок на способы проверки и игры проявляется нижняя грань, иконки и стрелки реагируют на наведение. Кнопка «Пауза движения» на главной и в меню останавливает фон и 3D-сцену; настройка живёт только в памяти страницы. При `prefers-reduced-motion: reduce` дым отображается статичным кадром, частицы скрыты, появления заменены короткими затуханиями, вместо 3D-сцены стоит постер. Декоративная контрольная панель удалена: главная сразу ведёт к действующим способам проверки.

Меню и инструкция открываются как модальные панели с возвратом фокуса на кнопку, закрываются по Escape, кнопке и клику за пределами панели. На странице проверки переключатели работают стрелками, Home и End. Лучи логотипа рисуются при входе, буквы поднимаются из масок, затем знак едва заметно пульсирует; на главной знак в шапке проявляется, когда большое слово уходит при прокрутке. При успешном копировании терминал показывает сканирующий импульс и короткий разлёт частиц. Анимации маршрута, открытия панелей, появления при прокрутке и переходы между страницами при `prefers-reduced-motion: reduce` заменяются затуханиями; постоянная анимация ставится на паузу в скрытой вкладке. Для основных текстов используется размер 16 px или больше.

## Скрипты и границы проверки

PowerShell собирает имена, PID и доступные пути процессов. Расширенный сценарий может вычислять SHA-256 файлов `.exe`, `.dll`, `.asi`, `.jar` в выбранной пользователем папке; объём обхода ограничен. CMD сохраняет список процессов в CSV. Скрипты не используют сеть, требуют подтверждения и сохраняют файлы локально. Отсутствие подписи, путь или хеш без проверенного эталона не доказывают нарушение.

Команды на странице проверки — самостоятельная локальная диагностика, не часть официальной удалённой проверки. В частности, [ReallyWorld прямо запрещает проверяющему запускать CMD/PowerShell через AnyDesk](https://reallyworld.ru/anydesk). Поиск по имени файла или процесса не определяет факт читерства; конкретные правила серверов и версии клиентов нужно сверять отдельно. Страница инструментов ссылается только на сайты авторов программ и официальные правила FunTime/ReallyWorld.

Юридические тексты содержат предоставленные владельцем имя и резервный номер телефона. Перед действующим коммерческим запуском владелец должен заполнить отмеченные реквизиты, подтвердить схему обработки данных и утвердить редакцию документов. Законодательная основа для отдельного согласия: [статья 9 Федерального закона № 152-ФЗ](https://mintrud.gov.ru/docs/laws/130).
